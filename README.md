# SchemeMatch

A voice-first app that tells Indian citizens, in their own language, which government welfare schemes they are likely eligible for, why, which documents they need and where to apply.

**Status:** Week 3. Engine, API and the AI rule-extraction pipeline are built. The staging API (testing only; rules are AI-checked, not yet human-reviewed) is at https://schemematch-api-zakuroooos-projects.vercel.app/schemes. First eval: [reports/eval-2026-10-20.md](reports/eval-2026-10-20.md).
